# Drill #11 정리: 소년 AutoRun(자동 무적 런) 상태 추가

## 1. 과제 한 줄 요약

기존 소년 캐릭터의 상태 머신(Idle ↔ Run)에 **AutoRun 상태**를 새로 추가한다. Idle에서 `a` 키를 누르면 키 입력 없이도 소년이 크고 빠르게 좌우로 계속 달리고, 일정 시간이 지나거나 방향키를 누르면 다른 상태로 돌아간다.

## 2. 동작 방식

### 2-1. AutoRun 상태에 들어가기

- **Idle** 상태에서 `a` 키를 누르면 AutoRun 상태가 된다.
- 들어가는 순간부터는 키를 아무것도 누르지 않아도 소년이 스스로 좌우로 이동한다.

### 2-2. AutoRun 상태에서의 모습

- 평소 Run 상태보다 **이동 속도가 빠르다.**
- 소년의 **크기가 더 크게** 그려진다.
- 화면 **왼쪽 끝이나 오른쪽 끝에 닿으면 방향이 자동으로 바뀐다.** (벽에 부딪히면 반대로 달리는 방식)

### 2-3. AutoRun 상태에서 빠져나가기

| 조건                                        | 다음 상태      | 설명                                                        |
| ------------------------------------------- | -------------- | ----------------------------------------------------------- |
| AutoRun에 들어간 뒤 **5초 이상** 경과 | **Idle** | 시간이 다 되면 달리기를 멈추고 대기 상태로 복귀             |
| **방향키**를 누름                     | **Run**  | 무적 런이 취소되고, 누른 방향으로 달리는 기본 Run 상태가 됨 |

## 3. 구현할 때 지켜야 할 점

- **반드시 `AutoRun` 상태 클래스를 새로 만들어서** 구현한다.
- 상태 다이어그램을 직접 그려서 **이미지 파일로 저장소에 포함**해 제출한다.
- 이 과제는 AI를 사용해 개발하는 과제이다.

## 4. 구현 계획

- `AutoRun.enter()`: 진입 시각 기록, 속도와 크기를 키움, 방향 초기값 설정
- `AutoRun.do()`: 이동, 화면 끝(좌/우) 도달 시 방향 반전, 진입 후 5초 경과 여부 확인
- `AutoRun.exit()`: 크기와 속도를 원래대로 복구
- `AutoRun.draw()`: 확대된 크기로 스프라이트 그리기
- 상태 전이 규칙에 `Idle → AutoRun`(a 키), `AutoRun → Idle`(시간 만료), `AutoRun → Run`(방향키)을 추가

## 5. 채점 기준 체크리스트 (총 5점)

`a` 키를 누르면 AutoRun 상태로 이동한다 (1점)

5초 이상 경과하면 Idle 상태로 복귀한다 (1점)

AutoRun에서 소년의 속도가 빨라지고 크기가 커진다 (1점)

AutoRun에서 좌우 화면 끝에서 자동으로 방향이 전환된다 (1점)

상태 다이어그램을 제출한다 (1점)

## 6. 제출 시 주의 사항

- 개발 과정의 **커밋 기록을 충분하고** **적절하게**남긴다. (기능 단위로 나눠서 커밋)
- 개발 기획·요구사항 문서인 **`PRD.md`를 반드시 포함**한다.
